# Iron Rotation

A phone app for the 10-week mass program, adapted for dumbbells and bodyweight. It opens on today's workout:

- Mon: Chest & Triceps
- Tue: Back & Biceps
- Wed: Abs (4 routines, rotates weekly)
- Thu: Shoulders & Forearms
- Fri: Legs
- Sat/Sun: Rest

Tap a set to check it off (starts a rest timer). Weights are remembered per exercise.

## Put it on your phone
1. Create a GitHub repo and upload every file in this folder to the root.
2. Repo Settings > Pages > Deploy from branch > `main` / root > Save.
3. Open `https://YOUR-USERNAME.github.io/REPO-NAME/` on your phone.
4. iPhone: Safari > Share > Add to Home Screen. Android: Chrome menu > Install app.

It works offline after the first load.
